MIJN EETDAGBOEK

Gebruik het dagboek als app

De website is alleen bedoeld om de app op je beginscherm te zetten. Voeg hem toe en open daarna het eetdagboek via het nieuwe icoon.

Zo zet je de app op je beginscherm

  1. Open deze site via een https://-adres in Safari.
  2. Tik op Deel (het vierkant met de pijl omhoog) en kies Zet op beginscherm.
  3. Tik op Voeg toe en open daarna het eetdagboek via het nieuwe icoon.

Een gedeelde link opent de site. Je moet deze stappen daarna zelf in Safari afronden. Pushmeldingen vereisen iOS 16.4 of nieuwer.

Development

Vul de dev-code in die in de terminal staat na npm start om het dagboek in je browser te openen. De code staat lokaal in data/dev-code.json; stel zelf een code in met de omgevingsvariabele DEV_CODE.

Pushmeldingen laden…

De app op een iPhone zetten
  1. Open deze site via een https://-adres in Safari.
  2. Tik op Deel en kies Zet op beginscherm.
  3. Open de nieuwe eetdagboek-app vanaf je beginscherm en schakel hierboven meldingen in.

Je kunt hierboven de link delen. Op een iPhone moet de ontvanger de site in Safari openen en zelf op Deel → Zet op beginscherm tikken; iOS staat installatie via alleen een link niet toe.

Pushmeldingen op iPhone vereisen iOS 16.4 of nieuwer en dat de site aan het beginscherm is toegevoegd.

De server moet blijven draaien om herinneringen op tijd te versturen.

Je dagboek wordt veilig opgeslagen via de ingestelde server.
