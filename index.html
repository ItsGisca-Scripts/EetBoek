Log in op je eetdagboek

Hier kan je inloggen met de code die je van Gijs hij blijft ingelogd tot je zelf uitlogd.

Op je iPhone zetten

  1. Open deze website in Safari.
  2. Tik op Deel (het vierkantje met de pijl omhoog).
  3. Scrol in het menu en tik op Zet op beginscherm.
  4. Tik op Voeg toe. Open het dagboek daarna via het nieuwe beginschermicoon.
